Frequently Asked Questions

How does the color extractor determine dominant colors?

The tool samples the image pixels on an HTML5 canvas and runs an adaptive quantization clustering algorithm. By grouping nearby chromatic values and ignoring extreme outliers, it identifies the primary aesthetic tones that define the composition.

Can I copy colors directly to my Tailwind or CSS stylesheets?

Yes! Simply click the "Copy CSS" button above the palette. It formats your extracted palette as ready-to-paste CSS custom properties (--color-primary, --color-accent, etc.).

Is my artwork uploaded to a server?

No. Your files never leave your computer. All pixel calculations and eyedropper loupe magnification happen directly in your browser's local memory using the HTML5 Canvas API.
